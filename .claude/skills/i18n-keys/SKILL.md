# Тексты интерфейса на трёх языках

Сайт с первого дня работает на `ru`, `ky` и `en`. Строка, добавленная только в один файл, на других языках покажет русский текст (или ключ), поэтому ключи всегда добавляются во все три файла сразу.

## Шаг 1. Выбери пространство имён и ключ

Пространства имён: `common`, `nav`, `auth`, `catalog`, `lesson`, `exercise`, `runner`, `dashboard`, `profile`, `reports`, `admin`, `errors`, `seo`.

Ключ в camelCase описывает смысл: `exercise.showSolution`, `lesson.translationPending`, `catalog.lessonsCount`. Перед созданием поищи — возможно, подходящий ключ уже есть в `common` («Сохранить», «Отмена», «Назад»).

## Шаг 2. Добавь во все три файла

```jsonc
// messages/ru.json
"catalog": {
  "lessonsCount": "{count, plural, one {# урок} few {# урока} many {# уроков} other {# урока}}",
  "price": "{price, number} сом",
  "startCourse": "Начать курс"
}

// messages/ky.json — черновик, проверит носитель
"catalog": {
  "lessonsCount": "{count, number} сабак",
  "price": "{price, number} сом",
  "startCourse": "Курсту баштоо"
}

// messages/en.json
"catalog": {
  "lessonsCount": "{count, plural, one {# lesson} other {# lessons}}",
  "price": "{price, number} som",
  "startCourse": "Start course"
}
```

## Множественное число

| Язык | Правило | Пример |
|---|---|---|
| Русский | Формы `one` (1, 21), `few` (2–4, 22–24), `many` (5–20, 25…), `other` (дроби) | 1 урок, 3 урока, 5 уроков |
| Кыргызский | Существительное после числа **не меняется**, `plural` не нужен | 1 сабак, 5 сабак |
| Английский | `one`, `other` | 1 lesson, 5 lessons |

## Шаг 3. Используй в коде

```tsx
// серверный компонент
const t = await getTranslations('catalog');
// клиентский компонент
const t = useTranslations('catalog');

t('lessonsCount', { count: course.lessonsCount });
```

Не склеивай строку из частей (`t('start') + ' ' + name`): порядок слов в кыргызском другой. Используй подстановку: `"greeting": "Привет, {name}!"`.

## Коды ошибок

Каждый код из `docs/DOMAIN-SHARED.md`, раздел 6, имеет перевод в `errors.<CODE>` (`errors.LESSON_LOCKED`), а правила валидации — в `errors.validation.<rule>`. Новый код ошибки из API — сразу три перевода.

## Кыргызский — правила для агента

- Пиши простым литературным кыргызским, без калек с русского там, где есть устоявшееся слово.
- Технические термины бери из `glossary.yaml` репозитория `edu-content`, если термин там есть.
- **Все новые и изменённые ключи `ky` перечисли в описании PR** в разделе «Кыргызские строки на проверку» — их проверит носитель языка.

## Проверка

- Наборы ключей в трёх файлах совпадают (если в проекте есть `pnpm i18n:check` — запусти).
- Переключи сайт на `ky` и `en` и посмотри экран: длинные кыргызские и английские слова не должны ломать вёрстку на 375 px.
