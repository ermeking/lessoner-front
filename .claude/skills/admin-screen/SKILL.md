# Экран админки

Админкой пользуются владелец и ревьюеры каждый день. Главное — предсказуемость: все экраны устроены одинаково, опасные действия защищены, после каждого действия видно, что произошло.

## Структура

```
src/app/[locale]/admin/reports/page.tsx      тонкий маршрут
src/features/admin-reports/
├─ reports-table.tsx        таблица + фильтры + пагинация
├─ report-status-dialog.tsx форма/диалог действия
└─ columns.tsx              определение колонок
```

## Список: таблица с пагинацией в URL

```tsx
'use client';
import { useSearchParams } from 'next/navigation';
import { useRouter, usePathname } from '@/i18n/navigation';
import { useReactTable, getCoreRowModel } from '@tanstack/react-table';
import { useAdminReportsList } from '@/gen';

export function ReportsTable() {
  const params = useSearchParams();
  const router = useRouter();
  const pathname = usePathname();
  const page = Number(params.get('page') ?? 1);
  const status = params.get('status') ?? 'OPEN';

  const { data, isPending, error } = useAdminReportsList({ page, pageSize: 20, status });

  const table = useReactTable({
    data: data?.items ?? [],
    columns,
    getCoreRowModel: getCoreRowModel(),
    manualPagination: true,
    rowCount: data?.total ?? 0,
  });

  const setParam = (key: string, value: string) => {
    const next = new URLSearchParams(params);
    next.set(key, value);
    if (key !== 'page') next.set('page', '1');
    router.replace(`${pathname}?${next.toString()}`);
  };

  // рендер: фильтры → таблица (скелетон / ошибка / пусто / строки) → пагинация
}
```

Фильтры и номер страницы живут в URL: ссылку на отфильтрованный список можно отправить коллеге, а кнопка «Назад» работает.

## Форма

- react-hook-form + `zodResolver` со схемой от Kubb.
- Кнопка отправки заблокирована, пока идёт запрос.
- `VALIDATION_ERROR` раскладывается по полям (скилл `api-integration`), остальные ошибки — во всплывающее уведомление.
- Несохранённые изменения: при уходе со страницы с изменённой формой — предупреждение.

## Опасные действия

Удаление, снятие с публикации, блокировка, отзыв доступа — только через диалог подтверждения:

- заголовок называет действие и объект: «Снять с публикации урок "Переменные" (ky)?»;
- текст объясняет последствия: «Ученики увидят русскую версию с плашкой "Перевод готовится"»;
- кнопка подтверждения — деструктивного стиля и с глаголом действия, а не «ОК».

## Роли

Настоящие права проверяет API, UI только не показывает лишнего:

| Раздел | REVIEWER | ADMIN |
|---|---|---|
| Контент, переводы, очередь проверки | ✓ | ✓ |
| Обращения, статистика | ✓ | ✓ |
| Пользователи, блокировка, выдача доступа | — | ✓ |

## Редакторы контента

- Markdown-редактор (CodeMirror) с предпросмотром через `lib/markdown` — тот же рендер, что увидит ученик.
- Экран перевода: слева русский оригинал только для чтения, справа редактор, сверху статус (`DRAFT` / `REVIEW` / `PUBLISHED`) и допустимые переходы.
- Редактор задания: кнопка «Прогнать эталон» запускает `solution` против `tests` через раннер и показывает результат. Сохранить задание, где эталон не проходит тесты, можно только с явным подтверждением.

## Проверка экрана

- Загрузка, ошибка, пустой список — у каждого своё состояние.
- После каждой мутации — уведомление и обновлённые данные без перезагрузки страницы.
- Экран работает на планшете (ширина 768 px).
