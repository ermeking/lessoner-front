# Компоненты и вёрстка

- **Серверный компонент по умолчанию.** `'use client'` ставится на самый маленький интерактивный компонент, а не на всю страницу.
- **Где живёт код.** Код фичи — в `src/features/<фича>/`, общие компоненты — в `src/shared/ui/`. В `src/app/` только тонкие файлы маршрутов.
- **UI-компоненты.** Используй shadcn/ui из `shared/ui`. Не подключай другие UI-библиотеки.
- **Стили.** Только Tailwind. Цвета — только через токены темы (`bg-background`, `text-muted-foreground`, …), без хардкода `#hex` и `bg-white`: иначе ломается тёмная тема.
- **Мобильная версия в приоритете.** Базовые классы пишутся для телефона, `md:` и `lg:` добавляют десктоп. Области нажатия не меньше 44 px. Никакой горизонтальной прокрутки на ширине 375 px, кроме таблиц и блоков кода.
- **Тексты.** Все строки — через `useTranslations` / `getTranslations`, строки прямо в JSX запрещены (включая `alt`, `aria-label`, `placeholder`).
- **Доступность.** Семантические теги (`button` для действий, `a`/`Link` для переходов), у полей есть `label`, фокус виден, у иконок-кнопок есть `aria-label`.
- **Ссылки.** Используй `Link` из `@/i18n/navigation`, чтобы сохранялся языковой префикс.
- **Изображения** — через `next/image`, иконки — из `lucide-react`.
- **Состояния.** Каждый экран с данными обрабатывает загрузку (скелетон), ошибку (текст по коду) и пустое состояние.
