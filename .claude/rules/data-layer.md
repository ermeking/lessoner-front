# Слой данных

- **Только Kubb.** К API обращаются только через сгенерированный код из `src/gen`: функции на сервере, хуки TanStack Query в браузере. Ручной `fetch('/api/...')` запрещён.
- **Нет эндпоинта — не придумывай его.** Опиши в PR, какой эндпоинт нужен, и остановись на этой части задачи.
- **Режим рендера** страницы берётся из таблицы `docs/ARCHITECTURE-FRONTEND.md`, раздел 4: кешируемые страницы запрашивают данные без куки, динамические — с кукой.
- **Мутации** выполняются только из браузера через хуки. После мутации инвалидируются связанные запросы, а если мутация влияет на серверно отрендеренную страницу — вызывается `router.refresh()`.
- **Ошибки.** Все ошибки — `ApiError` с полем `code`. Пользователю показывается перевод `errors.<code>`, а не `message` с сервера. Ответ 404 на сервере превращается в `notFound()`.
- **Токены.** Никаких токенов в JS: сессия живёт только в httpOnly-куке.
- **Состояние.** Не дублируй серверные данные в `useState` / контексте — источник истины — кеш TanStack Query.
- **Отдельный модуль на сервере.** Серверные обёртки над запросами фичи лежат в `features/<фича>/server.ts` и не импортируются в клиентские компоненты.
