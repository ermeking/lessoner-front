# Админка

- **Устройство.** Админка работает только в браузере (клиентские компоненты), рассчитана на десктоп и планшет, `noindex`. Шаблон экрана — скилл `admin-screen`.
- **Права.** Настоящие права проверяет API. UI только скрывает действия, недоступные роли (`REVIEWER` не видит управление пользователями), но на скрытие не полагается.
- **Опасные действия** (удаление, снятие с публикации, блокировка, отзыв доступа) выполняются только после диалога подтверждения, где названо, что именно произойдёт.
- **Списки** с серверной пагинацией; фильтры и страница хранятся в search params URL, чтобы ссылку можно было отправить.
- **Формы** на react-hook-form + zod-схема от Kubb. Ошибки `VALIDATION_ERROR` из `details` раскладываются по полям.
- **Обратная связь.** Результат каждой мутации показывается всплывающим уведомлением; кнопка отправки блокируется на время запроса.
- **Контент.** Предпросмотр контента использует тот же `lib/markdown`, что и сайт, — ученик должен увидеть ровно то, что видит ревьюер.
