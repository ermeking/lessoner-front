# Рендер Markdown

- **Единственный путь.** `lib/markdown` — единственный способ превратить Markdown в интерфейс: уроки, условия заданий, описания курсов, статические страницы, предпросмотр в админке.
- **Санитизация обязательна.** `rehype-sanitize` не отключается. Схема разрешает только то, что описано в `docs/CONTENT-FORMAT-SHARED.md`, раздел 5. Сырой HTML из контента не проходит.
- **Рендер в React.** Результат превращается в React-элементы через `hast-util-to-jsx-runtime`. `dangerouslySetInnerHTML` не используется.
- **Свои компоненты** подставляются для выносок (`note`/`tip`/`warning`), блоков кода (кнопка «Копировать»), таблиц (горизонтальная прокрутка) и картинок (`next/image`).
- **Новые элементы разметки** (например, новый тип выноски) сначала появляются в `docs/CONTENT-FORMAT-SHARED.md` и в `edu-content`, потом здесь.
- **Тесты.** У модуля есть юнит-тесты на санитизацию (`<script>`, `onerror`, `javascript:`-ссылки) — при изменениях они должны проходить.
