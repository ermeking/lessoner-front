# Тесты

- **Юнит-тесты** (Vitest + Testing Library) лежат рядом с кодом: `*.test.ts(x)`. Покрываем чистую логику и критичные модули: `lib/markdown`, преобразование ошибок, форматтеры, редьюсер состояния задания.
- **e2e-тесты** (Playwright) лежат в `e2e/` и проверяют пользовательские сценарии против локального API с сидом. Раннер проверяется только в e2e, в реальном браузере.
- **Селекторы** — по роли и доступному имени (`getByRole('button', { name: … })`), а не по CSS-классам. Если нужен `data-testid`, называй его по смыслу.
- **Мобильный проект.** В конфигурации Playwright есть проект с шириной 375 px: ключевые сценарии гоняются и на нём.
- **Нельзя «чинить» тест под сломанное поведение.** Если тест противоречит `docs/DOMAIN-SHARED.md` или тексту задачи, прав документ.
