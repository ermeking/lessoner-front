# Переводы интерфейса

- **Три файла.** Каждый ключ есть во всех трёх файлах: `messages/ru.json`, `ky.json`, `en.json`. Структура файлов одинаковая.
- **Пространства имён:** `common`, `nav`, `auth`, `catalog`, `lesson`, `exercise`, `runner`, `dashboard`, `profile`, `reports`, `admin`, `errors`, `seo`. Новое пространство имён добавляется только если ни одно не подходит.
- **Ключи** в camelCase и описывают смысл, а не текст: `lesson.translationPending`, а не `lesson.perevodGotovitsya`.
- **Ошибки API.** Каждый код из `docs/DOMAIN-SHARED.md`, раздел 6, есть в `errors.<CODE>`.
- **Множественное число** — только через ICU. Русский: `one`, `few`, `many`, `other`; кыргызский: существительное после числа не меняется; английский: `one`, `other`. Подробности в скилле `i18n-keys`.
- **Кыргызские строки,** написанные агентом, — черновик. Список новых ключей `ky` обязательно идёт в описании PR для проверки носителем.
- **Строки не склеиваются** из кусочков: переменные подставляются через ICU (`{name}`, `{count}`).
