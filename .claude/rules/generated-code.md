# Сгенерированный код

- **`src/gen` не редактируется вручную никогда.** Любая правка пропадёт при следующей генерации.
- **Перегенерация:** `pnpm api:gen` при запущенном локальном API. Результат коммитится вместе с задачей.
- **Если сгенерированные типы выглядят неправильно** (`any`, `unknown`, дубли enum), проблема в описании API. Опиши её в PR для `edu-api`, а не исправляй в `src/gen`.
- **Изменения `kubb.config.ts`** затрагивают весь проект: только по задаче и с перегенерацией всего клиента.
