## Завершено
- **WEB-01 · Каркас edu-web** — 2026-09-15. Next.js 16 (App Router, Turbopack) + TypeScript strict + Tailwind v4 + shadcn/ui (Radix, Nova, lucide-react); next-intl (ru/ky/en, `localePrefix: always`, откат на ru через `getMessageFallback` с предупреждением в dev); тема через next-themes (переключатель в шапке, запоминается); шапка/подвал с переключателями языка и темы и кнопкой «Войти»; шрифты Noto Sans + JetBrains Mono через `next/font/google` (подтверждена поддержка ө/ү/ң на `/[locale]/dev/fonts`, доступна только в dev); Vitest + Playwright (проекты desktop и mobile-375) настроены и зелёные; ESLint + Prettier; Dockerfile (`output: 'standalone'`) и CI (`lint`, `typecheck`, `test`, `build` на push/PR; e2e — отдельный workflow по `workflow_dispatch`).

## Принятые решения
- **Next.js 16, не 15.** `create-next-app@latest` установил 16.3.5 — она вышла позже базы знаний агента. Ключевое отличие: файл `middleware.ts` переименован в `proxy.ts` (сама функция осталась прежней, next-intl продолжает работать как есть). Использован `proxy.ts` — актуальная конвенция. `next lint` в v16 удалён — скрипт `lint` в `package.json` вызывает `eslint .` напрямую.
- **Тексты на `/dev/fonts` — не через next-intl.** Страница служебная (видна только при `NODE_ENV=development`, в проде `notFound()`) и не часть продуктового интерфейса, поэтому статичные строки на английском оставлены как есть, в отличие от общего правила «никаких строк в JSX». Дальнейшие dev-страницы (markdown — WEB-04, runner — WEB-08) можно вести так же.
- **Логотип-заглушка — только иконка.** Название продукта ещё не выбрано (`platform-concept.md`, раздел 11), поэтому в шапке иконка `GraduationCap` без текста бренда, а не выдуманное название.
- **Навигация в шапке пока пустая.** У платформы ещё нет страниц каталога (WEB-05), поэтому вместо пустого декоративного `<nav>` в разметке — просто спейсер; реальные пункты меню добавятся вместе со страницами.
- **`@types/node` поднят до `^22`** (вместо `^20` от `create-next-app`) — этого требует peer-зависимость `vitest@5`, и версия соответствует установленному Node 22.

## Замечено по пути
- В dev-консоли браузера при каждой навигации появляется предупреждение React 19.2 «Encountered a script tag while rendering React component» — источник не наш код, а сам пакет `next-themes` (использует `<script dangerouslySetInnerHTML>` для анти-FOUC инъекции темы до гидратации). Функциональность не страдает, но стоит последить за апдейтами `next-themes` на случай, если авторы поправят под React 19.2.
